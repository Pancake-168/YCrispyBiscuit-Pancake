# 图片转换功能设计文档

---

## 一、功能概述

"图片转换"（Picture Switch）是 Pancake 工具箱的图片处理模块。核心能力：

- 所有常见图片格式的相互转换
- 附带分辨率调整（等比缩放、指定宽高）
- 附带文件体积压缩（质量调节、有损/无损切换）
- 单文件与批量处理

整个功能完全走 Python FastAPI 后端，不涉及 Rust 侧代码。

---

## 二、格式覆盖

### 2.1 目标支持的格式

| 格式        | 全称                             | 读（输入） | 写（输出） | 说明                                           |
| ----------- | -------------------------------- | ---------- | ---------- | ---------------------------------------------- |
| PNG         | Portable Network Graphics        | ✅         | ✅         | 无损，支持透明通道（RGBA）                     |
| JPEG/JPG    | Joint Photographic Experts Group | ✅         | ✅         | 有损，不支持透明，质量 1-100                   |
| WebP        | Web Picture                      | ✅         | ✅         | 无损/有损均可，支持透明，体积小                |
| BMP         | Bitmap                           | ✅         | ✅         | 无压缩位图，体积大                             |
| TIFF/TIF    | Tagged Image File Format         | ✅         | ✅         | 支持多页、多种压缩                             |
| GIF         | Graphics Interchange Format      | ✅         | ✅         | 支持动画帧，最多 256 色                        |
| ICO         | Icon                             | ✅         | ✅         | 多尺寸图标文件                                 |
| AVIF        | AV1 Image File Format            | ✅         | ✅         | 新一代格式，压缩率高                           |
| HEIF/HEIC   | High Efficiency Image File       | ✅         | ❌         | Apple 格式，仅支持读取（写需额外专利授权风险） |
| SVG         | Scalable Vector Graphics         | ✅         | ✅         | 矢量格式，输出时栅格化                         |
| PPM/PGM/PBM | Netpbm formats                   | ✅         | ✅         | 中间格式，极少直接使用                         |
| TGA         | Truevision Targa                 | ✅         | ✅         | 游戏/3D 常用                                   |

### 2.2 相互转换矩阵

除 HEIF/HEIC 仅输入外，其余 11 种格式之间均可互转。

格式特有限制：

- **透明通道**：PNG/WebP/TIFF/TGA → JPEG/BMP/GIF 时，透明背景自动填充白色
- **动画 GIF**：转为静态格式时取首帧；转回 GIF 时仅首帧有效
- **调色板模式**：GIF/BMP(8bit)/PNG(8bit) 相互转换时自动量化
- **色彩深度**：高位深→低位深自动降位，低位深→高位深不增加真实精度
- **SVG → 栅格**：需指定渲染分辨率，默认等比适配（fit）到 1920×1080 边界内（长边不超出，短边按比例缩放）

#### 转换图片

```
POST /api/picture/convert
```

请求类型：`multipart/form-data`

| 字段                | 类型     | 必填 | 默认值      | 说明                                      |
| ------------------- | -------- | ---- | ----------- | ----------------------------------------- |
| `files`             | `File[]` | ✅   | —           | 待转换图片，最多 50 个                    |
| `target_format`     | `str`    | ✅   | —           | 目标格式，见 output_formats               |
| `quality`           | `int`    | ❌   | —           | 有损格式的质量参数，JPEG/WebP/AVIF 1-100  |
| `lossless`          | `bool`   | ❌   | `false`     | WebP/AVIF 无损模式（与 quality 互斥）     |
| `resize_mode`       | `str`    | ❌   | `"none"`    | 缩放模式                                  |
| `max_width`         | `int`    | ❌   | —           | 最大宽度（px），等比缩放                  |
| `max_height`        | `int`    | ❌   | —           | 最大高度（px），等比缩放                  |
| `width`             | `int`    | ❌   | —           | 精确宽度（resize_mode=`exact` 时使用）    |
| `height`            | `int`    | ❌   | —           | 精确高度（resize_mode=`exact` 时使用）    |
| `keep_aspect_ratio` | `bool`   | ❌   | `true`      | 缩放时保持宽高比                          |
| `background_color`  | `str`    | ❌   | `"#FFFFFF"` | 透明转不透明时的填充色                    |
| `color_mode`        | `str`    | ❌   | `"auto"`    | 色彩模式：auto/RGB/RGBA/L(灰度)/P(调色板) |
| `strip_metadata`    | `bool`   | ❌   | `true`      | 移除 Exif/IPTC/XMP 等元数据               |

**resize_mode 说明：**

| 值      | 行为                                                     |
| ------- | -------------------------------------------------------- |
| `none`  | 不缩放，保持原始尺寸                                     |
| `fit`   | 等比缩放到 max_width × max_height 范围内（图片完整可见） |
| `fill`  | 等比缩放填满 max_width × max_height（超出部分裁剪）      |
| `exact` | 强制缩放到 width × height，不保持比例                    |

### 3.3 Controller（PictureController.py）

> **实现注意**：`multipart/form-data` 在 FastAPI 中不能直接用 Pydantic 模型作为 Body 参数——每个字段必须用 `Form()` 逐个声明。`ConvertRequest` Schema 保留用于类型组织和文档生成，但不直接用作路由函数的 Body 参数。

```python
from fastapi import APIRouter, UploadFile, File, Form, Query
from typing import List, Optional
from app.schemas.PictureSchema import (
    ConvertResponse,
    FormatsResponse,
)
from app.services.PictureService import PictureService

router = APIRouter()
service = PictureService()


@router.get(
    "/picture/formats",
    summary="获取支持的图片格式列表",
    tags=["Picture"],
    response_model=FormatsResponse,
)
async def get_formats():
    return await service.get_supported_formats()


@router.post(
    "/picture/convert",
    summary="转换图片格式",
    tags=["Picture"],
    response_model=ConvertResponse,
)
async def convert_picture(
    # multipart/form-data 中每个字段必须用 Form() 逐个声明
    # ConvertRequest Schema 只用于类型文档，不作为 Body 直接使用
    files: List[UploadFile] = File(..., description="待转换图片"),
    target_format: str = Form(..., description="目标格式"),
    quality: Optional[int] = Form(None, ge=0, le=100),
```

### 3.4 Service（PictureService.py）

核心逻辑流程：

```
1. 接收 Multipart
2. 逐个处理：
   a. 文件大小校验（后端防御性检查，单文件 >100MB 拒绝）
   b. 检测输入格式（文件头魔数） → 验证是否为支持格式
   c. 打开图片（Pillow Image.open / pyavif / pillow-heif）
   d. 色彩模式转换（RGBA→RGB if JPEG target, 灰度等）
   e. resize（按 resize_mode）
   f. 另存为目标格式（quality/lossless 参数）
   g. 计算压缩比、尺寸信息
3. 组装响应
4. 批量文件打包 zip
```

Python 依赖：

```
Pillow>=10.0          # 核心图像处理
pillow-heif>=0.15     # HEIF/HEIC 读取
pyavif               # AVIF 读写
cairosvg>=2.7         # SVG 栅格化渲染
```

### 3.5 Schema（PictureSchema.py）

```python
from pydantic import BaseModel, Field
from typing import Optional, List, Literal


class FormatDetail(BaseModel):
    extensions: List[str]
    mime_type: str
    supports_transparency: bool
    supports_animation: bool
    lossy_options: bool
    quality_range: Optional[List[int]] = None


class FormatsResponse(BaseModel):
    input_formats: List[str]
    output_formats: List[str]
    format_details: dict[str, FormatDetail]


class ConvertRequest(BaseModel):
    target_format: str = Field(..., description="目标格式扩展名")
    quality: Optional[int] = Field(default=None, ge=0, le=100)
    lossless: bool = False
    resize_mode: Literal["none", "fit", "fill", "exact"] = "none"
    max_width: Optional[int] = Field(default=None, ge=1, le=16384)
    max_height: Optional[int] = Field(default=None, ge=1, le=16384)
    width: Optional[int] = Field(default=None, ge=1, le=16384)
    height: Optional[int] = Field(default=None, ge=1, le=16384)
    keep_aspect_ratio: bool = True
    background_color: str = "#FFFFFF"
    color_mode: Literal["auto", "RGB", "RGBA", "L", "P"] = "auto"
    strip_metadata: bool = True


class ConvertResultItem(BaseModel):
    index: int
    original_name: str
    converted_name: str
    original_format: str
    target_format: str
    original_size: int       # bytes
    converted_size: int      # bytes
    original_resolution: str  # "W×H"
    converted_resolution: str
    compression_ratio: float
    status: Literal["success", "error"]
    error: Optional[str] = None


class ConvertResponse(BaseModel):
    task_id: str
    total: int
    results: List[ConvertResultItem]
    zip_url: Optional[str] = None
```

### 5.4 前端交互流程

```
1. 初始态：EmptyState（"拖拽图片到此处，或点击选择"）

2. 文件选取：
   - Tauri 桌面端 → @tauri-apps/plugin-dialog open() 原生文件选择器
   - 纯 Web 端 → <input type="file" accept="image/*" multiple>
   - 拖拽 → Drop zone 监听 drop 事件
   → 前端本地过滤：仅保留支持格式、单文件 ≤ 100MB

3. 文件列表展示：
   - 每个文件一行：缩略图、文件名、原始格式、原始分辨率、文件大小
   - 可单独移除某个文件
   - 可清空全部
   - 显示总数和总大小

4. 参数设置：
   - 选择目标格式（Select），切换时下方质量滑块/无损开关联动显示/隐藏
   - JPEG 目标：显示质量滑块（1-100）
   - WebP/AVIF 目标：显示"质量优先"和"无损压缩"两个选项（Switch 切换）
   - PNG/BMP/TIFF 目标：无质量参数（这些格式的特性）
   - 缩放模式（Select）：不缩放 / 等比适配 / 等比填充 / 精确尺寸
   - 宽高输入根据缩放模式显示/隐藏

5. 提交转换：
   - 按钮显示文件数量
   - 点击后一次性将所有文件通过 multipart 提交到 POST /api/picture/convert
   - 后端顺序处理所有文件，前端等待完整响应
   - 前端展示整体进度条（已完成数 / 总数），后端处理期间不展示逐文件中间状态
   - 响应返回后一次性展示所有结果（成功/失败）
   - Toast 通知转换结果摘要
   - 显示压缩统计：总体积减少 XX%、共节省 XX MB

6. 下载：
   - 单文件：每行"下载"按钮，GET /api/picture/download/single/{task_id}/{index}
   - 打包下载：顶部"下载全部结果"按钮，GET /api/picture/download/batch/{task_id}
   - Tauri 桌面端用原生保存对话框，Web 端用 <a download>
```

```ts
  files: File[],
  params: ConvertParams
): Promise<ConvertResponse> {
  const formData = new FormData();
  files.forEach(f => formData.append('files', f));
  Object.entries(params).forEach(([k, v]) => {
    if (v !== undefined && v !== null) formData.append(k, String(v));
  });
  const res = await fetch(`${API_BASE}/api/picture/convert`, {
    method: 'POST',
    body: formData,
  });
  return res.json();
}

export function getSingleDownloadUrl(taskId: string, index: number): string {
  return `${API_BASE}/api/picture/download/single/${taskId}/${index}`;
}

export function getBatchDownloadUrl(taskId: string): string {
```

## 六、格式处理细节

### 6.1 各格式转换注意事项

| 场景                 | 处理方式                                                                  |
| -------------------- | ------------------------------------------------------------------------- |
| 任何格式 → JPEG      | 强制转为 RGB（丢弃透明通道），透明区域填充背景色                          |
| 任何格式 → PNG       | 保留透明通道（如果原图有），输出时可选 optimize=True                      |
| 任何格式 → WebP      | 有 alpha 保留 alpha；lossless=True 时忽略 quality                         |
| 任何格式 → GIF       | 转为调色板模式（最多 256 色）；原动画取首帧                               |
| GIF(动画) → 其他     | 逐帧导出为序列（暂不实现，一期仅取首帧）                                  |
| 任何格式 → ICO       | 非方形输入先居中裁切为正方形，再降采样为 16/32/48/256 多尺寸              |
| 任何格式 → AVIF      | 编码耗时长（比 JPEG 慢 10-50 倍，大分辨率时更显著），建议先 resize 再编码 |
| SVG → 任何栅格       | 用 cairosvg 渲染后按普通图片处理                                          |
| 高位深(16bit) → 8bit | Pillow 自动降位                                                           |
| CMYK → RGB           | 自动转换                                                                  |

### 6.2 质量参数适用范围

| 目标格式 | quality 参数 | lossless 参数 | 说明                                                                                          |
| -------- | ------------ | ------------- | --------------------------------------------------------------------------------------------- |
| JPEG     | ✅（1-100）  | ❌            | 典型值 75-95；100 文件仍比 BMP 小                                                             |
| WebP     | ✅（0-100）  | ✅            | lossless=True 时忽略 quality                                                                  |
| AVIF     | ✅（0-100）  | ⚠️            | 通过 pyavif 编码，非 Pillow 原生 save()，需通过临时文件读写；quality 参数透传至 pyavif 编码器 |
| PNG      | ❌           | —             | 默认无损，仅 Optimize flag                                                                    |
| BMP      | ❌           | —             | 无压缩                                                                                        |
| TIFF     | ❌           | —             | 可选 LZW/ZIP 压缩                                                                             |
| GIF      | ❌           | —             | 调色板即可                                                                                    |
| ICO      | ❌           | —             | 多尺寸封装                                                                                    |
| TGA      | ❌           | —             | 无压缩或 RLE                                                                                  |
| SVG      | ❌           | —             | 矢量文本                                                                                      |

## 七、错误处理

| 错误场景                | HTTP 状态码                    | 前端处理                        |
| ----------------------- | ------------------------------ | ------------------------------- |
| 文件非图片 / 格式不支持 | 200（results 中 status=error） | 该文件标记失败，其余继续        |
| 文件损坏                | 200（results 中 status=error） | 同上                            |
| 文件过大（>100MB）      | 400（后端拒绝）                | 前端上传前过滤 + 后端防御性校验 |
| 所有文件均失败          | 200（results 全部 error）      | Toast 通知"全部转换失败"        |
| 后端处理异常（OOM 等）  | 500                            | Toast 通知"服务异常，请重试"    |
| 任务 ID 不存在          | 404                            | 跳回初始态                      |

## 八、性能考虑

| 场景                     | 策略                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| 批量处理                 | 后端顺序处理（避免 Pillow 多图同时加载 OOM），前端单次 multipart 提交                                           |
| 超大图片（如 8000×6000） | 先 resize 再编码，避免一次性加载过大像素缓冲区                                                                  |
| 临时文件清理             | 任务完成后 10 分钟自动清理，或在下次启动时清理 temp/ 目录                                                       |
| AVIF 编码                | 耗时较长（比 JPEG 慢 10-50 倍，大分辨率时更显著），前端显示"处理中"时需告知用户 AVIF 较慢，建议先 resize 再编码 |
| 并发请求                 | 不支持同一客户端并行提交两个转换任务（前端禁用按钮直到完成）                                                    |
